Accessibility Statement

Our commitment to making this website accessible to everyone.

Conformance Status

✓ WCAG 2.2 Level AA — Conforms

This website, sushilchauhan28.github.io/sushil-a11y, is designed and maintained to conform to WCAG 2.2 Level AA. It has been built and tested by an IAAP triple-certified accessibility engineer using keyboard-only navigation, NVDA, JAWS, and VoiceOver on macOS and iOS.

The site uses semantic HTML5, proper heading hierarchy, visible focus indicators, sufficient colour contrast (minimum 4.5:1 for normal text), and a color scheme toggle supporting System, Light, and Dark preferences.

Measures Taken

  • Semantic HTML structure with correct landmark regions (<header>, <main>, <nav>, <footer>)
  • Logical heading hierarchy — no skipped levels
  • All interactive elements operable by keyboard only
  • Visible focus indicators on all focusable elements (minimum 2px outline)
  • Colour contrast: all text ≥ 4.5:1; large text ≥ 3:1; UI components ≥ 3:1
  • Color scheme toggle tested in System, Light, and Dark modes
  • Skip link provided to bypass navigation
  • prefers-reduced-motion respected — all transitions disabled at 0.01ms
  • prefers-color-scheme respected as the System default
  • No content that flashes more than 3 times per second
  • All images have appropriate alt text or are marked decorative
  • Page titles are unique and descriptive on every page
  • Language declared on every page (lang="en")
  • Current page indicated in navigation with aria-current="page" plus visual bold + background + accent border cues
  • Tested with NVDA + Chrome, JAWS + Chrome, VoiceOver + Safari (macOS and iOS)

Known Limitations

The WAS Practice Quiz page uses JavaScript-generated content. All quiz questions, answer options, and result announcements use aria-live="assertive" regions and are keyboard accessible. If you experience any issues navigating the quiz with a screen reader, please contact me directly.

Code blocks in blog posts are scrollable horizontally on narrow viewports. They are accessible via keyboard. If any code example is inaccessible, please report it.
